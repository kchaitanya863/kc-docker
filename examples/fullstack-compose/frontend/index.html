📦 Boxr Full-Stack Cluster

Status: ONLINE

This multi-container application is coordinated and orchestrated by boxr compose.

Architecture:

  • Frontend Web Service: Python Web Server (Port 8080)
  • Backend API: Python REST API (Port 5000)
  • Database & Cache: Redis Alpine (Port 6379)
  • Storage: Persistent Volumes for Cache & Data

API Endpoints:

GET / (Service Info)

GET /health (Health Status)

GET /items (Stored Data)
